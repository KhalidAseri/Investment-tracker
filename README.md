# مسار

تطبيق شخصي لمتابعة المحفظة وخطة الاستقلال المالي: الأوزان المستهدفة، مخطط الإيداع، التوقعات والدخل بعد الاستقلال، التقويم المالي، وربط يومي بتقارير Interactive Brokers.

- الواجهة: React + Vite، تُنشر تلقائياً على GitHub Pages عند كل دفع إلى `main`.
- البيانات: Supabase (مشروع `mahfazati`) مع حماية الصفوف لكل مستخدم ومزامنة فورية بين الأجهزة.
- التحديث اليومي: الدالة `supabase/functions/daily-update` تُشغَّل بجدولة pg_cron الساعة 5 صباحاً بتوقيت الرياض، وبعد إغلاق تداول. تحدّث أسعار الصرف والأسعار (Yahoo للأسهم والصناديق المتداولة، ومباشر لصناديق الاستثمار السعودية)، وتزامن IBKR، وتحفظ لقطة يومية، وترسل إشعارات الجوال.
- الإشعارات: Web Push بمفاتيح VAPID تُولَّد على الخادم وتُحفظ في Vault فقط.
- المتابعة العائلية: صاحب المحفظة يضيف بريداً في `portfolio_viewers` فيقرأ صاحبه البيانات دون تعديل.
- الزكاة: 2.5% من كل أصل عليه زكاة، ويحدّد المالك حكم كل أصل (`holdings.zakatable`) وبداية حوله (`zakat_start`)، وتتكرر المواعيد بالتقويم الهجري (أم القرى).
- التوزيعات: لكل أصل تكرار التوزيع ونسبته أو مبلغه للوحدة وموعده القادم وتاريخ استحقاقه (`payout_*`, `maturity_date`)، وصفحة «التوزيعات» تعرض ما وصل وما ينتظر.
- الدخل الشهري: محرك يحسب دخل السنة (نسبة من القيمة أو من الربح أو مبلغ ثابت) مع قواعد الحماية، ومصادره، وخطة البيع لتعبئة الاحتياطي، وجدول التحويلات (`plan_settings.income_*`).

للمعاينة محلياً ببيانات تجريبية: `npm install && npm run dev` ثم افتح الرابط مع `?demo` (وأضف `&viewer` لمعاينة وضع المتابعة).
