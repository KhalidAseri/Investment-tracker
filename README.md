# استثماراتي — مرشد المحفظة

تطبيق ويب (PWA) يعمل على الجوال لتتبّع كل استثماراتك وتوجيه قراراتك: التوزيع على كل المحاور، المخاطر، الخطة، الدخل، الزكاة والمراجعات الدورية. البيانات تُحفظ على جهازك فقط.

**الرابط:** https://khalidaseri.github.io/Investment-tracker/

## ماذا يفعل

| التبويب | الوظيفة |
|---|---|
| الرئيسية | صافي القيمة، «المطلوب منك الآن»، تقدّم الهدف، لمحة التوزيع |
| الأصول | أسهم وصناديق بأسعار مباشرة، وأصول يدوية (ادخار جهة العمل، نقد، عقار)، ذهب بالجرام |
| التحليل | حلقة وخريطة عالم وخريطة شجرية تفاعلية: الفئة، الدول، المناطق، القطاعات، المراكز، العملة، الجهة، السيولة؛ التركّزات؛ الفعلي مقابل المستهدف؛ «وين أحط المبلغ القادم؟» |
| الخطة | خارطة البناء، صندوق الطوارئ، الهدف، خطة الدخل (المعادلة، الطبقات الثلاث، التحويلة السنوية، قواعد الحماية)، الزكاة، المراجعة |
| حسابي | الربط والمزامنة، توزيعات الأصول (يسجّلها كلود)، الإعدادات والمظهر، دليل المستثمر، المشاركة |

## التقنية

- Next.js 14 (تصدير ثابت) + Tailwind + `motion`. نسختان من نفس الكود: الموقع تحت `/Investment-tracker`، وتطبيق أندرويد عبر Capacitor 7 (`BUILD_TARGET=native`).
- `src/lib/engine/` — منطق الحسابات كدوال صافية مع اختبارات وحدات (`npm test`).
- **المخزن المشترك** (`src/lib/cloud.ts`): مشروع Supabase؛ جداول `invest_*` فقط تخص هذا التطبيق. بعد الدخول تُزامَن المحفظة، ويقرأ كلود الأصول ويكتب توزيع كل أصل. الطريقة موثّقة في [`docs/asset-profiling.md`](docs/asset-profiling.md).
- **الأسعار** (`src/lib/market-client.ts`): Yahoo Finance. داخل تطبيق أندرويد تُطلب مباشرة؛ في المتصفح عبر وسطاء CORS مجانيين غير مضموني التوفر، وعند التعذّر يُعرض آخر سعر محفوظ أو سعر يدخله المستخدم.
- نظام التصميم (فاتح/داكن) في `src/app/globals.css`؛ خريطة العالم تُولَّد بـ `node scripts/build-world.mjs`.

```bash
npm install
npm test                 # اختبارات محرّك الحسابات
npm run dev              # http://localhost:3000/Investment-tracker
npx next build           # نسخة الموقع في out/
npm run android:apk      # نسخة التطبيق + APK (يتطلب Android SDK و android/keystore.properties للتوقيع)
```

مفتاح توقيع التطبيق لا يُرفع للمستودع؛ `android/keystore.properties` يشير إليه.

## تنبيه

أداة تنظيم وتثقيف وليست استشارة مالية أو ضريبية أو فتوى. تقديرات الزكاة والعوائد افتراضات قابلة للتعديل.
