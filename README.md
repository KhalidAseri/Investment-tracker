# استثماراتي — مرشد المحفظة

تطبيق ويب (PWA) يعمل على الجوال لتتبّع كل استثماراتك وتوجيه قراراتك: التوزيع على كل المحاور، المخاطر، الخطة، الدخل، الزكاة والمراجعات الدورية. البيانات تُحفظ على جهازك فقط.

**الرابط:** https://khalidaseri.github.io/Investment-tracker/

## ماذا يفعل

| التبويب | الوظيفة |
|---|---|
| الرئيسية | صافي القيمة، «المطلوب منك الآن»، تقدّم الهدف، لمحة التوزيع |
| الأصول | أسهم وصناديق بأسعار مباشرة، وأصول يدوية (ادخار جهة العمل، نقد، عقار)، ذهب بالجرام |
| التحليل | التوزيع حسب الفئة/الجغرافيا/القطاع/العملة/الجهة/السيولة، التركّزات، الفعلي مقابل المستهدف، «وين أحط المبلغ القادم؟» |
| الخطة | خارطة البناء، صندوق الطوارئ، الهدف، خطة الدخل (المعادلة، الطبقات الثلاث، التحويلة السنوية، قواعد الحماية)، الزكاة، المراجعة |
| المزيد | التوزيعات، دليل المستثمر، مشاركة برابط للقراءة فقط، الإعدادات والنسخ الاحتياطي |

## التقنية

- Next.js 14 (تصدير ثابت) + Tailwind، بلا خادم. التخزين في `localStorage` تحت مفتاح واحد مُرقَّم الإصدار (`investtrack_v3`).
- `src/lib/engine/` — منطق الحسابات كدوال صافية (تقييم، تعرّض، توجيه، خطة، دخل، زكاة، مراجعة، مشاركة) مع اختبارات وحدات.
- `src/lib/market-client.ts` — الأسعار من Yahoo Finance عبر وسطاء CORS عامة مجانية مع بدائل وذاكرة مؤقتة. **غير مضمونة التوفر**؛ عند التعذّر يُعرض آخر سعر محفوظ أو سعر يدخله المستخدم.

```bash
npm install
npm test          # اختبارات محرّك الحسابات
npm run dev       # http://localhost:3000/Investment-tracker
npx next build    # الناتج في out/
```

## تنبيه

أداة تنظيم وتثقيف وليست استشارة مالية أو ضريبية أو فتوى. تقديرات الزكاة والعوائد افتراضات قابلة للتعديل.
